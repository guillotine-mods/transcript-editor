Transcript Editor

Listen to each recorded line of a game, fix its text, and mark it checked.

  1. Click Choose game folder and pick the game’s folder on your computer. If you got a .zip, unzip it first. A CD has to be copied to your computer.
  2. The browser asks whether this page may edit files in that folder. Choose Allow (or Allow on every visit).
  3. Your work saves by itself into the game folder. Next time, Continue with … picks up where you stopped.

This browser can’t save into a folder. Please open this file in Google Chrome or Microsoft Edge.

You can still listen and edit here, then press Download my edits and send the file back.
